# API к устройству UltraScale Architecture Soft Error Mitigation (SEM) Controller

API позволяет отправлять команды и считать данные, обрабатывая их и формируя human readable вывод в консоль; позволяет протестировать устройство.

Общение с устройством происходит по UART. Итоговая программа используется на отладочной плате: под Linux на ARM архитектуре.

## Не поддерживается:
- SSI устройства и SLR. Данное API предусмотрено только для устройства, использующего однин контроллер SEM.
- PFA адреса в конфигурационной памяти. Используйте команду трансляции из PFA в LFA адрес, после чего полученный адрес можно передать другим командам.

## Не гарантируется работоспособность:
- для UltraScale архитектуры, потому что отличается формат LFA адреса по сравнению с UltraScale+;
- для устройств кроме XCZU15, потому что может отличаться максимальное количество фрагментов конфигурационной памяти (Configuration Frames) для других устройств.

## Компиляция программы

Используется компилятор gcc из тулчейна для ARM процессоров, который позволяет выполнить кросс-компиляцию под Linux (arm-gnu-toolchain-12.2.rel1-x86_64-aarch64-none-linux-gnu).

Для компиляции программы указан путь до копилятора, который должен лежать рядом с папкой проекта: ./../arm-gnu-toolchain-12.2.rel1-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu-gcc
Затем можно выполнить сборку с помощью make:

   ```bash
   make
   ```

Также можно указать путь до другого компилятора. Нужно изменить переменную "CC" в Makefile:

   ```bash
   make CC="./path/to/compiler"
   ```

Переменная "CFLAGS" содержит флаги для компиляции. Например, их можно изменить таким образом:

   ```bash
   make CFLAGS="-Wall -std=c11 -I./.include"
   ```

Предусмотрена цель "clean" для очистки build-дериктории:

   ```bash
   make clean
   ```
